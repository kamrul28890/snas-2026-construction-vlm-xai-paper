\section{Artifact Map}

Key artifacts:

\begin{itemize}
\item \texttt{benchmark/rules.json}: normalized safety rules.
\item \texttt{benchmark/splits/}: pilot image-rule manifest.
\item \texttt{benchmark/annotations/}: bootstrap annotation templates and completed model-assisted annotations.
\item \texttt{benchmark/interventions/}: frozen intervention specs.
\item \texttt{results/frozen\_model\_outputs/}: normalized baseline outputs.
\item \texttt{results/tables/}: generated score tables.
\end{itemize}
