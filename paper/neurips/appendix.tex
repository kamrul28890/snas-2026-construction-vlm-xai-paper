\section{Detailed Results and Reproducibility Status}

This appendix records the concrete artifacts, counts, and result tables currently implemented in the repository. All numbers in this appendix are generated from checked artifacts rather than manually annotated human ground truth. The model-assisted annotation layer remains a bootstrap reference for pipeline validation and audit prioritization.

\subsection{Implemented Artifact Set}

The current scaffold contains the following reproducible components:

\begin{itemize}
\item \path{benchmark/rules.json}: four normalized construction-safety rules: PPE hard hat, fall harness, guardrail edge, and struck-by equipment.
\item \path{benchmark/prompts/}: prompt templates for normalized model adapters.
\item \path{benchmark/splits/pilot_manifest.csv}: 163 pilot image-rule pairs.
\item \path{benchmark/splits/scaleup_candidate_manifest.csv}: 588 scale-up candidate image-rule pairs.
\item \path{benchmark/annotations/}: pilot and scale-up model-assisted annotation layers, annotation templates, human-audit protocol, and the first human-audit queue.
\item \path{benchmark/interventions/}: 948 frozen pilot intervention specifications.
\item Frozen model outputs: \path{results/frozen_model_outputs/}. These include deterministic baselines and local Florence-2 grounding outputs.
\item \path{results/intervention_outputs/}: Florence-2 outputs after targeted and matched-random occlusions.
\item \path{results/tables/}: aggregate score tables, per-example score files, slice diagnostics, intervention summaries, and human-audit status.
\item \path{results/release_manifest.json}: SHA-256 manifest for 158 checked artifacts.
\end{itemize}

The repository also contains \texttt{human\_audit\_batch\_001}, a balanced 120-row audit queue prioritized from scale-up Florence/bootstrap disagreements and weak evidence-overlap cases. It has 30 rows per rule. Among these 120 rows, 118 are Florence/bootstrap answer disagreements, 82 have nonambiguous bootstrap labels, 83 are marked as rule-applicable, 59 have low evidence IoU, and one has missing predicted evidence. The current annotator fields are populated by two independent AI-generated audit passes: annotator A uses a strict compliance-officer persona and annotator B uses a pragmatic site-superintendent persona. A returned adjudication package resolves all 12 A/B answer-label disagreements. \subsection{Model Outputs and Answer-Level Scores}

The current model-output layer contains deterministic adapters and the first real local image-grounded adapter:

\begin{itemize}
\item \textbf{Annotation bootstrap}: echoes the model-assisted label and evidence.
\item \textbf{Manifest seed}: echoes the weak manifest label.
\item \textbf{Majority violation}: always predicts violation with no image evidence.
\item \textbf{Caption keyword}: uses only source captions and rule-specific keywords.
\item \textbf{Florence grounding}: runs \texttt{microsoft/Florence-2-base-ft} through the companion local grounding pipeline, then maps detections through deterministic geometry.
\end{itemize}

The Florence grounding adapter produced 163 pilot outputs and 588 scale-up outputs with zero invalid normalized answers. On the pilot split it predicted 111 compliant and 52 violation answers. On scale-up it predicted 399 compliant and 189 violation answers. The low answer accuracy relative to the bootstrap labels is not hidden; it is evidence that the current local grounding proxy is not a strong safety VQA model and should be treated as a diagnostic baseline.

\subsection{Intervention Specifications and Effects}

The frozen pilot intervention file contains 948 occlusions: 158 targeted rule-evidence masks and 790 matched-random controls. There are five matched-random controls per targeted mask, using the same clipped mask width and height as the corresponding target.

\begin{table}[h]
\centering
\caption{Pilot intervention specification counts.}
\input{tables/pilot_intervention_counts}
\end{table}

The Florence intervention run completed all 948 masked-image reruns using beam decoding and black-box masks. It produced 649 compliant and 299 violation outputs. The intervention results show the core faithfulness pattern: targeted evidence removal changes answers and evidence locations more than same-size random-location masking.

\begin{table}[h]
\centering
\caption{Pilot Florence intervention effects.}
\input{tables/pilot_intervention_effects}
\end{table}

The paired answer-flip difference is 30.0 percentage points with a bootstrap 95\% interval of 22.3 to 37.7 percentage points. The paired centroid-drift difference is 0.160 with a bootstrap 95\% interval of 0.133 to 0.187. Evidence disappearance occurred in 5.1\% of targeted rows and 3.7\% of matched-random rows, so disappearance is tracked separately from ordinary evidence relocation.

\subsection{Current Limits Before NeurIPS-Style Claims}

The implemented results are sufficient to show a reproducible benchmark scaffold and a meaningful faithfulness-audit workflow. They are not sufficient for final NeurIPS-style empirical claims. The remaining required work is independent human/domain annotation, agreement and adjudication reporting, additional instruction-following VLM adapters, and final review under the official target conference template.
