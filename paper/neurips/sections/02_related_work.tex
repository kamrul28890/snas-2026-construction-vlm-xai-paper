\section{Related Work}

\paragraph{Construction-safety VLMs.}
Construction-safety VLM work has begun to evaluate hazard identification, rule-based VQA, captioning, and grounding. ConstructionSite is the dataset foundation for this study because it links site imagery with captions, rule-violation records, and grounding metadata \citep{chen2025constructionsite}. We do not introduce a new detector; instead, we ask whether a VLM-style safety inspector uses the correct visual evidence when answering rule questions. Florence-2 is the first local image-grounded adapter in this repository because it supports prompted grounding and detection-style outputs \citep{xiao2024florence}.

\paragraph{Faithfulness and rationales.}
Prior XAI work shows that plausible explanations are not necessarily faithful; attention and rationales can be persuasive without being causal \citep{jain2019attention}. This motivates evaluating answer labels, evidence boxes, and counterfactual response separately. Perturbation tests are especially relevant for safety imagery because a faithful model should react more to masking a missing hard hat, unprotected edge, or worker-equipment proximity cue than to a same-size mask elsewhere.

\paragraph{Evaluation and datasets.}
The paper is framed as an evaluation artifact: benchmark schema, audit labels, model-output normalization, intervention protocol, score tables, and failure slices. This aligns with top-tier evaluation/dataset contributions rather than new-model claims. The safety framing follows risk-management guidance emphasizing documented scope, measurement limits, provenance, and prohibited high-stakes use \citep{nist2023airmf}.
