\section{Experimental Setup}

The experiment suite has three parts: answer scoring, evidence scoring, and counterfactual intervention. All adapters write the same normalized fields: answer label, evidence regions, invalid-output flag, and provenance metadata.

\begin{itemize}
\item \textbf{Annotation bootstrap}: echoes the model-assisted annotation labels and evidence.
\item \textbf{Florence grounding}: runs the local Florence-2 grounding pipeline from the companion XAI pilot and maps grounded detections through a deterministic geometric decision layer.
\item \textbf{Manifest seed}: echoes the pilot weak label from the manifest.
\item \textbf{Majority violation}: image-blind baseline that always predicts violation.
\item \textbf{Caption keyword}: caption-only leakage baseline using rule-specific keywords and no image pixels.
\end{itemize}

We evaluate these adapters on the pilot manifest, scale-up candidate manifest, and 120-row final audit-label layer. The intervention study is run for Florence on the pilot set because it is the first local image-grounded adapter with box-like outputs. The frozen intervention file contains 158 targeted masks and 790 matched-random controls. The current next empirical extension is to add instruction-following VLM adapters behind the same schema, record model version and decoding settings, and rerun both answer scoring and intervention scoring for the strongest model.
